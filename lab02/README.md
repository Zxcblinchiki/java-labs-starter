## Инварианты

Инвариант — то, что истинно для любого объекта класса в любой момент после выхода из конструктора. Конструктор не даёт создать объект, нарушающий инвариант, а каждый публичный метод либо сохраняет инвариант, либо бросает `IllegalArgumentException` и оставляет объект без изменений.

### `BankAccount`

- Баланс никогда не бывает отрицательным: `balance >= 0`.
  - Конструктор отклоняет отрицательный начальный баланс; нулевой допустим.
  - `withdraw` не даёт снять больше, чем есть на счёте, поэтому баланс может дойти до 0, но не ниже.
- Баланс меняется только через `deposit` и `withdraw`, и только на положительную сумму:
  - `deposit(amount)` увеличивает баланс ровно на `amount`, если `amount > 0`;
  - `withdraw(amount)` уменьшает баланс ровно на `amount`, если `0 < amount <= balance`.
- Неудачная операция (ноль, отрицательная сумма, нехватка средств) не меняет баланс.
- Поле `balance` закрыто (`private`), setter нет — изменить баланс в обход правил извне нельзя.

### `ProjectTask`

- `id` не `null` и не состоит только из пробелов; после создания не меняется (`final`, без setter).
- `title` не `null` и не состоит только из пробелов; после создания не меняется (`final`, без setter).
- `estimatedHours` всегда строго больше 0.
  - Конструктор отклоняет 0 и отрицательные значения.
  - Оценку можно только увеличить через `increaseEstimate` на положительное число часов; уменьшить или задать произвольно нельзя.
- `status` никогда не `null`.
  - Новая задача всегда создаётся в статусе `NOT_STARTED`.
  - Статус меняется только через `changeStatus`, который отклоняет `null`.
- Задача считается завершённой (`isCompleted() == true`) тогда и только тогда, когда её статус — `COMPLETED`.
- Неудачный вызов `changeStatus` или `increaseEstimate` не меняет состояние задачи.
